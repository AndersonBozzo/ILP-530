# Como iniciar
Instale JDK 25 e Maven 3.9.x. Abra o terminal na pasta de cada projeto e execute `mvn verify` ou `mvn spring-boot:run`.
Os projetos iniciais apenas iniciam o contexto Spring. A API ainda nao possui endpoints e a importacao ainda nao le o CSV. Adicione JPA e o driver PostgreSQL nas etapas correspondentes.
O GitHub Actions verifica compilacao e inicializacao, nao atribui notas. Testes oficiais de aceitacao serao adicionados separadamente. Consulte os arquivos em atividades/.
